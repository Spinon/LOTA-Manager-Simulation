================================================================================
2. VIDA, ARMADURA E EHP DE ESTRUTURAS
================================================================================

Multiplicador físico:

armorDamageMultiplier =
  1 - (0.06 * armor) / (1 + 0.06 * abs(armor))

Dano físico recebido:

physicalDamageTaken =
  incomingPhysicalDamage * armorDamageMultiplier

EHP físico:

effectiveHpPhysical =
  currentHealth / armorDamageMultiplier

Dano mágico recebido:

magicalDamageTaken =
  incomingMagicalDamage * (1 - magicResistance)

Dano puro recebido:

pureDamageTaken =
  incomingPureDamage

Para manager, estruturas podem ter modificador específico:

buildingIncomingDamage =
  rawDamage
  * damageTypeMultiplier
  * sourceVsBuildingMultiplier
  * fortificationMultiplier
  * backdoorMultiplier

================================================================================
5. BACKDOOR PROTECTION
================================================================================

Backdoor ativa quando não há creep aliado válido próximo da estrutura inimiga.

hasValidCreepNearby =
  count(alliedLaneCreepsWithinBackdoorRadius) > 0

backdoorProtectionActive =
  structure.hasBackdoorProtection
  && !hasValidCreepNearby

Raio sugerido:

backdoorRadius = 900

Redução de dano:

if backdoorProtectionActive:
  backdoorDamageMultiplier = 0.25
else:
  backdoorDamageMultiplier = 1.0

Regeneração durante backdoor:

if backdoorProtectionActive:
  structureRegen =
    baseRegen
    + backdoorBonusRegen
else:
  structureRegen = baseRegen

Sugestão:

backdoorBonusRegen = 90 health/s

Aplicação por tick:

structure.currentHealth =
  min(structure.maxHealth, structure.currentHealth + structureRegen * deltaTime)

================================================================================

Glyph ativo:

Duração:

glyphDurationSeconds = 7

Redução de dano durante glyph:

fortificationMultiplier = 0.0 ou 0.1

Modelo recomendado para manager:

if structure.isFortified:
  fortificationMultiplier = 0.05
else:
  fortificationMultiplier = 1.0

Cooldown:

glyphCooldownSeconds = 300

Refresh por queda de primeira torre de tier:

if firstTowerOfTierFalls:
  glyphCooldown = 0

Score de uso:

glyphUseScore =
  towerValueAtRisk
  + creepWaveThreat
  + enemySiegeCommitment
  + highGroundDefenseImportance
  - chanceToDefendWithoutGlyph
  - expectedFutureGlyphNeed

useGlyph =
  glyphAvailable && glyphUseScore > glyphThreshold

7. PRIORIDADE DE ALVO DA TORRE
================================================================================

A torre escolhe alvo por prioridade.

Prioridade sugerida:

1. Unidade atacando herói aliado sob torre.
2. Unidade inimiga atacando a própria torre.
3. Unidade inimiga mais próxima.
4. Creep de cerco.
5. Creep comum.
6. Summon.
7. Ilusão.

Score:

towerTargetScore =
  attackAllyHeroPriority
  + attackingTowerPriority
  + proximityScore
  + unitTypePriority
  + lowHealthLastHitWeight

target =
  maxBy(enemyUnitsInRange, towerTargetScore)

Troca de aggro por comando de ataque:

if enemyHeroIssuesAttackCommandAgainstAlliedHeroWithinTowerRange:
  towerAggroTarget = enemyHero
  aggroDuration = 2.5

================================================================================
13. FUNÇÕES TYPESCRIPT
================================================================================

export function armorDamageMultiplier(armor: number): number {
  return 1 - (0.06 * armor) / (1 + 0.06 * Math.abs(armor));
}

export function structureDamageTaken(input: {
  rawDamage: number;
  damageType: "physical" | "magical" | "pure";
  armor: number;
  magicResistance: number;
  sourceVsBuildingMultiplier: number;
  fortificationMultiplier: number;
  backdoorMultiplier: number;
}): number {
  let multiplier = 1;

  if (input.damageType === "physical") {
    multiplier *= armorDamageMultiplier(input.armor);
  }

  if (input.damageType === "magical") {
    multiplier *= 1 - input.magicResistance;
  }

  return Math.max(
    0,
    input.rawDamage
      * multiplier
      * input.sourceVsBuildingMultiplier
      * input.fortificationMultiplier
      * input.backdoorMultiplier
  );
}

export function expectedTimeToKillStructure(
  currentHealth: number,
  netSiegeDps: number
): number {
  return currentHealth / Math.max(1, netSiegeDps);
}

export function isBackdoorProtected(input: {
  hasBackdoorProtection: boolean;
  alliedCreepsNearby: number;
}): boolean {
  return input.hasBackdoorProtection && input.alliedCreepsNearby <= 0;
}

14. TESTES RECOMENDADOS
================================================================================

1. Torre com armor positiva reduz dano físico.
2. Backdoor reduz dano quando não há creep próximo.
3. Backdoor desativa quando creep aliado entra no raio.
4. Glyph reduz dano durante duração.
5. Torre escolhe herói que atacou herói aliado.
6. expectedTimeToKillStructure cai quando siegeDps sobe.
7. Barracks destruído aumenta força de wave.
8. Mega creeps ativam apenas quando todos barracks caem.
