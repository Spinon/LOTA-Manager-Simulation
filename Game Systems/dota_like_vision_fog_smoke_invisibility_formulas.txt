================================================================================
1. MODELO DE VISÃO
================================================================================

Cada unidade possui:

dayVision
nightVision
flyingVision
trueSightRadius
sharedVision
temporaryVisionSources

Visão ativa:

currentVision =
  isDay ? dayVision : nightVision

Se unidade tem flyingVision:

visionBlockedByTerrain = false

Se visão comum:

visionBlockedByTerrain = true

================================================================================
2. CICLO DIA/NOITE
================================================================================

Modelo simples:

dayDurationSeconds = 300
nightDurationSeconds = 300
cycleLength = dayDurationSeconds + nightDurationSeconds

cycleTime = gameTimeSeconds % cycleLength

isDay =
  cycleTime < dayDurationSeconds

isNight = !isDay

================================================================================
3. FOG OF WAR
================================================================================

Mapa em células:

cellVisibleToTeam =
  any(alliedVisionSource reveals cell)

cellKnownButNotVisible =
  cellWasSeenBefore && !cellVisibleNow

cellUnknown =
  !cellWasSeenBefore

Vision score:

mapVisionScore =
  sum(cellImportance * isVisible(cell))

================================================================================

Se alvo está em high ground e observador em low ground:

canSeeTarget =
  hasFlyingVision

uphillMissChance pode ser separado do sistema de visão.

treeBlock:

if lineSegment(observer, target) intersects treeBlocker:

================================================================================
10. TRUE SIGHT
================================================================================

True sight só revela se também houver visão normal ou regra permitir revelar diretamente.

Modelo simples:

revealedByTrueSight =
  enemyInTrueSightRadius

visible =
  hasNormalVision || revealedByTrueSight

Modelo mais rígido:

visible =
  hasNormalVision && (!invisible || revealedByTrueSight)

================================================================================
12. FUNÇÕES TYPESCRIPT
================================================================================

export function isDay(gameTimeSeconds: number): boolean {
  const cycle = 600;
  return gameTimeSeconds % cycle < 300;
}

export function currentVision(dayVision: number, nightVision: number, gameTimeSeconds: number): number {
  return isDay(gameTimeSeconds) ? dayVision : nightVision;
}

export function smokeBreaks(distanceToEnemyHero: number, smokeBreakRadius = 1025): boolean {
  return distanceToEnemyHero <= smokeBreakRadius;
}

export function visionScore(cells: Array<{ importance: number; visible: boolean }>): number {
  return cells.reduce((sum, cell) => sum + (cell.visible ? cell.importance : 0), 0);
}
